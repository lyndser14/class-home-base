Tips & FAQs

Quick Start

  • Select + Presentation to add a slideshow and give it a name. Google Slides share links can be pasted directly; for Canva, use the Canva embed code. Organize slideshows with optional folders using Manage.
  • Use the left toolbar for classroom tools. Minimize it when you want more room for your presentation.
  • Your presentations, folders, class lists, bookmarks, and custom settings are saved in this browser on this device. They do not automatically sync to another browser or device.

Presentation Tools

Memo: Save a quick message to display in the colored bar across the top of the presentation.

Voice Level: Display the current classroom voice expectation in the bottom information bar so students know how loudly they should be speaking. Customize voice-level names, numbers, and colors in Settings.

Supplies Needed: Show students which materials to have ready in the bottom information bar. Add or customize your classroom supplies in Settings.

Timer (Countdown & Stopwatch): Open Timer in the left toolbar and switch between Countdown Timer and Stopwatch. Both can appear in draggable, resizable pop-ups over your presentation. Use the × on a pop-up to close it.

  • Countdown Timer: Enter your starting time in the left toolbar, then start the countdown. In the pop-up, use Pause/Resume, adjust the remaining time with −10 sec, +10 sec, +1 min, or +5 min, or select Reset to stop the countdown and return to the starting time entered in the left toolbar (not zero). In Settings, choose Visual + Countdown or Countdown Only and turn the ending chime on or off.
  • Stopwatch: Counts upward from 00:00. Start or stop it as needed; Reset stops the stopwatch and returns it to 00:00 without closing the pop-up.

Clock: Open Clock to quickly peek at the current time in the toolbar. Choose Display on Presentation only when you want students to see it; the pop-out shows the time and date and can be dragged, resized, or hidden with ×.

Saved Classes & Student Lists

Manage your saved classes in one place, then choose the active class from the top bar. The selected class is used by both Random Name and Groups & Partners.

  • Select a Class: Click the current class name in the top bar. If you have class folders, hover over or click a folder to expand its lists, then select a class.
  • Manage Class Lists: Click the pencil next to the class selector to open Manage Classes & Student Lists. Add or edit classes and student names. There is no eight-class limit.
  • Class Folders: Create optional color-coded folders, assign classes to folders or leave them unfiled, and drag class lists or folder headings to reorder them or move classes between folders. Folders can be one level deep only.
  • Delete a Class Folder: Choose whether to keep its class lists (moving them out of the folder) or delete the folder and its class lists. Deleting class lists also removes their saved student names from Home Base, so consider making a backup first.
  • Random Name: Choose a student at random from the selected class. Turn on the option to prevent repeats until everyone has been chosen.
  • Groups & Partners: Make balanced groups from the selected class by choosing students per group or the number of groups. Select Shuffle Again for a new mix.
  • Keep Certain Students Apart: Optional. In a class list, add another student's name in parentheses, such as Haylee (Sadie). Separate multiple names with commas. Home Base will try to place those students in different groups and warn you if it cannot meet every separation note.

Saved Presentations & Folders

  • Add & Manage: Select + Presentation to add a slideshow, or Manage to organize saved presentations and folders.
  • Presentation Folders: Folders are optional and have their own colors. Standalone presentations and folders share the top tab bar. Hover over or click a folder to reveal its presentations in a floating menu.
  • Reorder: Drag tabs to change their order or move presentations into folders.
  • Delete a Folder: Choose whether to keep its presentations as standalone tabs or remove those saved presentation links from Home Base. The original Canva and Google Slides files are not deleted.

Bookmarks: Pre-save links to videos, frequently used websites, music, interactive activities, and other pages you display to your class throughout the day. Select + Add Bookmark, paste a website link, and choose a title and color. Click a saved bookmark to open it in a new browser tab without changing your Home Base presentation. Use the pencil to edit, the trash can to delete, or drag bookmarks to reorder them. Your bookmarks stay saved in this browser.

Can I customize the supplies and voice levels?

Yes. Open Settings to edit voice-level numbers, wording and colors or add custom supplies for your classroom.

Will my presentation update when I edit Canva or Google Slides?

Home Base displays the linked Canva or Google Slides presentation. After editing the original, click ↻ Refresh above the presentation to load the latest version. Refreshing may return that slideshow to slide 1.

Where is my information saved?

Backup & Restore is optional. Home Base saves presentation links, presentation and class folders, class lists, bookmarks, and preferences in the current browser on this device; these do not automatically sync between devices. Before switching browsers or devices, or updating Home Base, select Backup Data in Settings and save the downloaded JSON file. Use Import Data in the other copy to restore the saved setup. Your original Canva or Google Slides files are not included in the backup.

Why won't an embedded presentation load in a file preview?

Open the HTML file in a full web browser such as Chrome, Edge or Safari rather than a computer's file preview window.
